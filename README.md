# DriveEase 🚗

DriveEase is a modern driving school management platform built with **Next.js**. It helps manage students, instructors, driving lessons, schedules, and administrative tasks through an intuitive dashboard.

## ✨ Features

* User Authentication
* Student Management
* Instructor Management
* Course Management
* Lesson Scheduling
* Dashboard Analytics
* Responsive Design
* Secure API Integration

## 🛠️ Tech Stack

### Frontend

* Next.js
* React.js
* Tailwind CSS

### Backend

* Next.js API Routes
* Node.js

### Database

* PostgreSQL

### Authentication

* JWT / NextAuth.js (depending on implementation)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/MubasheeraUB/DriveEase---Next.js.git
```

### Navigate to the project folder

```bash
cd DriveEase---Next.js
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env.local` file and add:

```
DATABASE_URL=your_database_url
NEXTAUTH_SECRET=your_secret_key
NEXTAUTH_URL=http://localhost:3000
```

### Run the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
